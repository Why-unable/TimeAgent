# Today、Calendar 与 Tasks 前端页面

Calendar 和 Tasks 页面直接调用认证业务 API，不依赖 Agent。服务端状态由 TanStack Query
管理，所有写操作成功后按领域查询键失效并重新读取 PostgreSQL 权威数据。

Today 页面消费单一汇总端点，展示用户时区日期、日程/计划任务时间线、下一日程倒计时、
今日计划/截止/逾期任务、待处理提醒和服务端冲突。Today 与 Tasks 页面完成任务后会同时
失效 `today` 和 `tasks` 查询，避免两个事务视图短暂不一致。

Calendar 使用 FullCalendar v7，并按用户 IANA 时区提供月、周、日视图。可从日期或页面
按钮创建日程，从日历事件或范围列表打开详情抽屉，并执行带 `expected_version` 的编辑与
取消。事件来源以本地/外部颜色区分，取消事件保留历史但禁止继续编辑。

Tasks 页面提供 Inbox、今日、即将到期、逾期、已计划、进行中、已完成和全部筛选，并按
项目分组。任务卡片和编辑抽屉始终把 `due_at` 标记为“截止时间”，把
`planned_start_at` / `planned_end_at` 标记为“计划执行时间”。完成操作使用专用状态机
端点。

日历与任务页面按路由懒加载。全天事件、重复事件范围、拖拽高风险变更确认和冲突提示所需
后端契约尚不存在，因此不在 T028 中由前端伪造；这些能力应在对应领域/API 或 HITL 阶段
完成后接入。
