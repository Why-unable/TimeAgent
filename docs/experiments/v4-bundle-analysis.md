The build already splits Calendar, Chat, Planning, Task Editor, markdown rendering, and interaction surfaces. The main entry target `<500 kB` is **not met**. `@dnd-kit`, React, Lucide, and date/time libraries are present in emitted chunks; the repo does not include `rollup-plugin-visualizer`. A temporary Rollup module-size experiment produced `renderedLength` values that did not reconcile with emitted minified chunk sizes, so this report intentionally uses trustworthy emitted chunk sizes instead of presenting those module totals as precise attribution. No dependency was added to create a chart.

Recommendation: keep correctness first; if reducing startup transfer becomes a release goal, use a repeatable sourcemap/metafile analyzer and review route-level imports. Do not rewrite stable Calendar code solely to save a small amount of bundle weight.
